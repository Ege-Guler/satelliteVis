🛰️ SatImPredictor: Semantic Segmentation of Satellite Imagery

SatImPredictor is a lightweight, browser-based application designed to perform semantic segmentation on satellite images. Users can upload an image and select between different model variants to generate land-cover segmentation masks. It provides a fast and interactive way to assess how well different models perform across various terrain types.

🧠 Model Variants

The tool features four segmentation models — each trained with different validation splits of the dataset:

  • 15_val: 15% validation split
  • 20_val: 20% validation split
  • 25_val: 25% validation split
  • 30_val: 30% validation split

Each model is based on the DeepLabV3+ architecture with a ResNet-101 encoder and was trained over 15 epochs. They were evaluated using key segmentation metrics:

  • IoU (macro)
  • F1 Score (macro)
  • Precision (macro)
  • Per-class IoU for Urban, Agriculture, Forest, Water, and more

🔍 Observations

  • 15_val consistently outperformed others in macro IoU and F1 metrics.
  • 25_val and 20_val showed balanced performance and stable convergence.
  • 30_val had strong early learning but slightly lower performance overall.
  • Water class was segmented accurately across all models, showing the model's strength on high-contrast features.

🧰 Tech Stack

  • Frontend: Angular 16 (standalone components, Signals API)
  • UI Framework: Angular Material
  • Model Architecture: DeepLabV3+ with ResNet-101 encoder
  • Training Framework: PyTorch
  • Dataset: DeepGlobe Land Cover Classification Dataset
  • Deployment Environment: Google Colab (A100 GPU)
  • API Communication: REST (POST endpoints for model selection and image upload)
